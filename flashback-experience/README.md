# flashback-experience

A private, cinematic two-page experience: a password-protected entrance, then a synchronized flashback sequence.

**Status:** Phase 3 complete (password screen, server-side auth, grain, shake, success transition, audio unlock). The flashback page is a placeholder until Phase 4.

## Run locally
Requires Node 20.12 or newer.

```bash
npm install
cp .env.example .env     # then edit .env and set your own password + secret
npm run dev              # open http://localhost:5173
```

`npm run dev` starts the Express API (port 8787) and Vite (port 5173) together.

## Environment variables
| Name | Purpose |
| --- | --- |
| `FLASHBACK_PASSWORD` | The password visitors must enter. Never committed. |
| `SESSION_SECRET` | Long random string that signs the login cookie. |
| `PORT` | Optional, defaults to 8787. |

## How the password works
The browser sends the typed password to `POST /api/auth`. The server compares it (timing-safe) with `FLASHBACK_PASSWORD`, rate-limits to 5 wrong tries per minute per IP, and on success sets a signed, HttpOnly cookie valid for 6 hours. The password never appears in the JavaScript bundle.

## Production build (same as Render)
```bash
npm run build
NODE_ENV=production npm start
```

## Deploy on Render
Use a **Web Service** (not a Static Site). `render.yaml` is included.
- Build command: `npm install && npm run build`
- Start command: `npm start`
- Env vars: `FLASHBACK_PASSWORD` (set manually), `SESSION_SECRET` (auto-generated by `render.yaml`)
